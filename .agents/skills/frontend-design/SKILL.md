# Frontend Design

Approach this as the design lead at a design studio known for giving every client a distinct visual identity that is not mistaken for anyone else's.

## Core Rules for This Project (The Plan Audit)
- **Palette**:
  - Primary Brand: `#04724D` (Deep Brunswick Emerald Green)
  - Surface Crisp: `#F4F4F9` (Ghost Off-White)
  - Accent Soft: `#B8DBD9` (Powder Teal / Ice Blue-Green)
  - Secondary Slate: `#586F7C` (Steel Slate Gray)
  - Base Deep: `#000000` (Pure Obsidian Black)
- **Zero Emojis**: Never use character emojis (⚡, 👨‍👩‍👦‍👦, ⚖️, 🎙️, etc.). Use clean SVG vector icons (Lucide or Google Material Symbols).
- **Parallax & Motion**: Implement genuine parallax layers on hero and discovery reveals, subtle mouse-driven or scroll-driven depth, fluid micro-interactions, smooth state transitions.
- **Craft**: High visual contrast, crisp monospaced numerical formatting, card depth, and editorial typography.
